# Release 2.3.1

Dieses Release entfernt die redundanten Fortschrittspräfixe „Punkt 1 von 6“ bis „Punkt 6 von 6“ aus den eingeblendeten Szenentiteln. Die Namen der Szenen und der übrige Spielinhalt bleiben unverändert.

Ausgehend von Version 2.3.0; keine absichtlichen Änderungen an Rätseln, Klickbereichen, Dialogen, Grafiken, Musik oder Übergängen.
